# 기도음악 타이머

기도음악을 재생하고 정한 시간에 부드럽게 꺼 주는 안드로이드 앱입니다.

## 내려받기

휴대폰에서 아래 링크를 누르면 최신 버전 APK가 내려받아집니다.

https://github.com/morethantask-art/prayer-music-timer/releases/latest/download/PrayerMusicTimer.apk

## 처음 설치하는 방법

1. 위 링크를 눌러 내려받은 파일을 누릅니다.
2. "출처를 알 수 없는 앱" 허용을 물으면 허용합니다.
3. Play 프로텍트 경고가 나오면 "세부정보 → 무시하고 설치"를 누릅니다.

설치한 뒤에는 앱의 **기타 → 버전 정보**에서 새 버전을 확인하고 업데이트할 수 있습니다.
